# solana-bootcamp-intro

Intro to Solana programs from a Solana bootcamp. The code is in `Intro-to-solana-programmes-main/`:

- `index.ts`: connect to Solana and send a first transaction
- `vault.ts`: interact with a simple vault program

```bash
cd Intro-to-solana-programmes-main
npm install
npx ts-node index.ts
```
